# とてとてtracker

コレクター向け商品（ポケモンカード／遊戯王カード／ワンピースカード／ドラゴンボールカード／ベイブレード／腕時計／Nike／一番くじ／ちいかわ／LivePocket店舗抽選）の抽選販売・先着販売・受注販売情報をまとめたトラッカーです。抽選価格と転売相場を一覧で比較できます。

**公開ページ:** https://totetoteplus.github.io/totetote-tracker/

## 構成

- `index.html` — GitHub Pagesで公開している一般公開版（このリポジトリの`README`が指すページ）
- `profit_lottery_tracker.html` — 作者用のオリジナル版（SNS投稿文章の生成機能などを含む）

データは手動リサーチ・Web検索による収集情報を基にしており、可能な限り公式ソースを裏付けとして掲載しています。実際の応募・購入の際は、各チケットの「抽選ページを開く」リンクから必ず最新情報をご確認ください。
